# Sparsh Customer App

Customer-facing frontend for Sparsh Salon & Spa clients.

## Features
- **Landing Page**: Salon introduction, team highlights, services showcase, customer testimonials, and luxury branding.
- **Customer Auth**: Email/password registration, local login, and Google OAuth 2.0 integration.
- **Services Catalog**: Browse treatments and salon services with category filtering.
- **Appointment Booking**: Select desired services, date, time slots, and submit booking requests with instant status tracking.
- **Customer Profile**: View and edit customer profile, contact details, date of birth, and anniversary preferences.

## Development & Run Commands

```bash
# Install dependencies
npm install

# Start Vite dev server on port 5173
npm run dev

# Build production bundle
npm run build

# Preview production build
npm run preview
```

- **Local Port**: `http://localhost:5173`
- **Backend API Proxy**: `http://localhost:8080` (routes `/api` and `/uploads` proxy to Spring Boot)
